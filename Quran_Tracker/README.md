# 📖 Quran Tracker  

The **Quran Tracker** is a simple command-line tool to help you **track your daily Quran recitation** and maintain consistency with a streak system.  

It allows you to log which *Juz* or portion(s) you recite each day, keeps a history, and motivates you with a streak count.  

---

## ✨ Features  

- 📖 **Track Juz recitation**: Supports full Juz and partial Juz input like `5½`  
- 🔥 **Streak system**: Keeps track of consecutive days of recitation  
- 📅 **Daily history log** stored in `quran_streak.json`  
- ✅ **Smart input handling**: Accepts flexible formats (`2½`, `153/4`, `7 8½`, etc.)  
- 🚀 **Simple CLI tool** with instant feedback  

---

## 📂 Files  

- `quran_tracker.py` → Main script to run the tracker  
- `quran_streak.json` → Auto-generated data file that stores recitation history and streak info
